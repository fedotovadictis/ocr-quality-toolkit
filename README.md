# OCR Quality Toolkit

Инструмент для подготовки корпусов и оценки качества распознавания текста OCR.

## Возможности

- импорт OCR-корпусов;
- формирование манифеста в формате JSONL;
- чтение метаданных изображений;
- вычисление SHA-256 изображений;
- нормализация текста;
- вычисление CER/WER;
- формирование отчётов о качестве OCR.

## Требования

- Go 1.20 или новее.

## Запуск

Показать справку:

```powershell
go run ./cmd/ocrq
```

## Импорт корпуса MWS

Команда `import-mws` читает исходный файл `metadata.jsonl`, обрабатывает связанные изображения и создаёт манифест корпуса.

```powershell
go run ./cmd/ocrq import-mws `
    -metadata <путь-к-metadata.jsonl> `
    -output <путь-к-manifest.jsonl>
```

Пример:

```powershell
go run ./cmd/ocrq import-mws `
    -metadata testdata\mws\metadata.jsonl `
    -output manifest.jsonl
```

Параметры:

- `-metadata` — путь к исходному файлу `metadata.jsonl`;
- `-output` — путь к создаваемому файлу `manifest.jsonl`.

После завершения команда выводит статистику импорта:

- количество прочитанных строк;
- количество записей с подходящим типом задания;
- количество импортированных записей;
- количество отсутствующих или некорректных изображений;
- количество записей без эталонного текста.

## Формат выходного файла

Манифест записывается в формате JSONL. Каждая строка содержит отдельную запись корпуса.

Пример:

```json
{"id":"mws-1-ab12cd34ef56","image":"images/page.png","references":["Распознанный текст"],"language":"ru","task":"full-page OCR ru","width":1000,"height":1400,"format":"png","tags":["dataset-a"],"sha256":"..."}
```
